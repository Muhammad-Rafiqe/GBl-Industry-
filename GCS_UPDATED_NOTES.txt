GCS WEBSITE UPDATE — FRONT PAGE CATALOGUE, CURRENCY SYMBOLS & IMAGE DISPLAY

CHANGES
1. Products added from Admin > Product manager now also appear on the public homepage under Products & solutions, not only in Shop.
2. Homepage cards for admin-added products show their price and a Shop / Add to cart link.
3. Currency options now show names and symbols:
   GBP — British Pound (£)
   USD — US Dollar ($)
   EUR — Euro (€)
   PKR — Pakistani Rupee (Rs)
   The shop and admin product list show the symbol with the currency code.
4. Product images use object-fit: contain in a larger 300px display area, so the whole uploaded image is visible instead of being cropped.
5. Admin can replace a product image from the Edit Product page.
6. Image uploads are limited to 8 MB and PNG/JPG/JPEG/WEBP/GIF formats.

DEPLOY TO EXISTING RENDER WEBSITE
- Replace the Python file currently used by your Render service with GCS_Admin_Store_Updated.py contents.
- Keep the filename/module consistent with your Render Start Command. For example, if the file in GitHub is GCS_Admin_Store.py, paste this updated code into that same file and keep Start Command: gunicorn GCS_Admin_Store:app
- Commit changes to GitHub; Render should redeploy automatically.
- Ensure requirements include Flask and gunicorn. Example requirements.txt:
  Flask
  gunicorn
- Keep ADMIN_USERNAME, ADMIN_PASSWORD and FLASK_SECRET_KEY in Render Environment settings. Do not put real passwords into public source code.

IMPORTANT RENDER STORAGE NOTE
The app currently saves SQLite data in gcs_store.db and uploaded files in static_uploads/. On Render instances without a persistent disk or external storage, these local files may be lost on redeploy/restart. For reliable long-term products/orders/images, attach persistent storage and configure the database/upload paths for it, or move to managed PostgreSQL plus Cloudinary/S3-compatible image storage.

The catalogue's existing restrictions on BDO/GBL/GHB remain unchanged. This update does not remove those restrictions.
